# 💬 Overview

This is simple example of a logarithmic slider in Unity with automatic legend adjustment. When the value in the input field changes, the corresponding slider value is calculated and the slider is moved to the correct position. The reverse conversion works as well — when the slider changes, the input field is updated with the corresponding value.

The legend can be configured with any required number of elements and intervals. During initialization, the legend elements are automatically positioned at the correct locations corresponding to the slider values.

# 🚀 Usage

1. Get demo script 
2. Add `Slider` component to game object on UI canvas
3. Add `TMP Input field` (if you need)
4. Add callbacks
5. Profit

### Environment setup

For a better experience, you can set up an environment for local development. Since this project is developed with VS Code, all settings are provided for it.

1. Use `Monokai Pro` or `eppz!` theme
2. Use `FiraCode` font
3. Install extensions:
    - C#
    - C# Dev Kit
    - Unity
4. Enable `Inlay Hints` in C# extension
5. Install `Visual Studio Editor` package in Unity
6. Put `.editorconfig` in root project directory
7. Be cool
